# Nenek Kebayan — Huawei combined project (v0.18)

Open project.godot from THIS folder in Godot 4.7.2.
Our UI, three game modes, 3D maps and multiplayer rules are retained.
Huawei Account, Scan and ML integrations now have the supplied app configuration.
Real Huawei features need Android device testing; the desktop editor uses bundled
translations and gives an explanation for native-only features.

Settings > Controls & Display has three joystick visibility choices. Show on
Touch is the default. Solo mode says "1 human and 9 bots" and the host waiting
room uses "START". English is the default language, alongside Malay, Chinese and
Tamil choices. See docs/HUAWEI_COMBINED.md for configuration and test details.

The project archive includes a minimal public Huawei client configuration, not
the original JSON or its secret fields. Export using the existing Android preset.
