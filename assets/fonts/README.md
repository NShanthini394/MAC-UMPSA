# Bundled game fonts

- Cinzel variable: https://github.com/google/fonts/tree/main/ofl/cinzel
- Noto Sans variable: https://github.com/google/fonts/tree/main/ofl/notosans
- Noto Sans Tamil variable: https://github.com/google/fonts/tree/main/ofl/notosanstamil
- Noto Sans CJK SC Regular (Simplified Chinese): https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese

Downloaded from the official repositories. Each font's accompanying SIL Open
Font License is preserved in LICENSE-*.txt and included in game exports.

Headings use Cinzel SemiBold. Body text uses Noto Sans Medium and buttons use
Noto Sans SemiBold. The body font falls back to bundled Tamil and Simplified
Chinese fonts. All font resources remain available offline.
